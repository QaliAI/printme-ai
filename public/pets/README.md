# PrintMe Pets portfolio assets

These four original illustrative examples were made for this release using the built-in image-generation tool, with a fixed cap of four final images. No customer photographs, customer OpenAI key, customer paid generation endpoint or Printify orders were used. They are labeled as original examples in the UI, never customer results or testimonials. No exact likeness guarantee is made.

No competitor artwork, screenshots, marks or customer content were copied. Twenty-four style briefs are distinct art directions; only these four have portfolio illustrations.
