# Implementation notes

Fonts: Noto Sans Display Condensed Black for high-impact headings, Inter for all interface and body content. The production outlined logo SVGs require no font installation. The live-text SVGs allow editing but require designers to install the specified fonts or substitute deliberately. Font files are not included.

Use the stacked collage logo in expressive areas; use the horizontal variant at >= 220px and the clean utility wordmark where legibility is paramount. Reserve sticker icon for favicons and compact marks.

CSS files are starter tokens, not a completed design system. Never upscale the 344px reference image as production artwork.

Suggested folder mapping: `/public/brand/logos/`, `/public/brand/patterns/`, `/app/styles/brand-tokens.css`. Use existing repo conventions.

This package is a working reconstruction. Match letterform spacing to the approved reference and proof all vector pieces before final launch.
