# PrintMe.ai / PUNK COLLAGE BRAND KIT v1.0

A practical identity and designer/developer handoff kit inspired by the approved cut-paper logo.

**What is included:** real vector SVG reconstruction (outlined paths), editable-text design SVG, transparent and opaque PNGs, favicon exports, brand guidelines PDF (12 pages), reusable textures, typography recommendations, palettes, CSS and JSON tokens, interface direction, animation storyboard, seasonal campaign guidance, creative copy, QA checklist, and the original user-selected reference.

**Important status:** this is a *working creative reconstruction*, NOT an exact autotrace of the raster screenshot or trademark-cleared final identity. Compare the reconstructed logo with `06_References/APPROVED_CREATIVE_REFERENCE.png` and have the designer manually proof proportions, character forms, texture and registration before launch. All graphic lettering spells PrintMe.ai, but raster rendering and font conversion should be proofed in your target applications.

**Designer first:** open `03_Brand_Guidelines/PRINTME_BRAND_STANDARDS_v1.pdf` and `01_Logos/SVG_Editable/printme_primary_editable_text.svg`; use outlined SVGs for stable implementation. Keep editable files separately because modifying outlined paths is not equivalent to text editing.

**Developer first:** open `04_Developer_Handoff/brand-tokens.json`, `printme-tokens.css`, and `05_Designer_Brief/WEB_DESIGN_COMPONENT_SPEC.md`. Import/adjust tokens to existing Next.js repo; don't replace the existing commerce flows.

**Launch guardrails:** asset source/license checks, current provider validation, print-safe area QC, accurate product variants and prices, accessibility checks, and human approval are still required.

Brand phrase options: MAKE SHIT. PRINT SHIT. / YOUR IMAGINATION. NO PERMISSION REQUIRED. The first is an edgy campaign line; the second can be used across wider contexts.

No font files are included.
