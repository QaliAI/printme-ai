# Logo production / usage rules

**Status: WORKING RECONSTRUCTION; not trademark cleared; not yet a final approved vector master.**

The selected design originates from an AI-generated raster exploration. The exact original lettering and textural fragments need final manual cleanup. This package provides real outlined paths, editable layers and transparent exports to advance the redesign, not a claim of exact vector equivalence.

- Full stacked collage: expressive hero, large poster compositions, inside packaging. Recommended displayed width >= 240px.
- Horizontal collage: desktop header when >= 220px width. Test lower widths; use clean utility wordmark if necessary.
- Utility black/white wordmarks: forms, email, checkout, legal/footer surfaces.
- Sticker icon: favicon and mobile icon; test at 32px, 48px, and 180px.
- One-color alternatives: production stamping, monochrome print and low-cost labels.
- Clearspace: >= 10% of total artwork height around collage, >= 1x the height of the lowercase x around utility wordmark.
- Never warp, recolor each letter, add drop-shadow gradients, hide under noise, stack on busy photo without solid backing, or use full textured logo at unreadable sizes.
- Do not refer to this as a registered mark until a legal check has been completed.
- All vector SVGs are outlined; edit the editable-text version for typography changes and rebuild outlines before shipping.
