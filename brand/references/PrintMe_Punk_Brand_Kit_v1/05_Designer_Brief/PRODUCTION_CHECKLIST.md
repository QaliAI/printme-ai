[ ] Approve exact final vector logo against selected raster reference at 100%, 25% and 32px icon
[ ] Designer checks letter spacing, visual alignment, torn-paper edges and copyright/trademark searches
[ ] Document variants with minimum sizes and safe areas
[ ] Verify font sourcing and license (no unauthorized proprietary files)
[ ] Verify interface body text contrast and legibility
[ ] Test keyboard, focus, reduced motion and mobile upload path
[ ] Review hero animation under throttled mobile CPU/network conditions
[ ] Verify real sample provenance and generate/print functionality
[ ] Test mockup mapping to actual print area, product, variant and print resolution
[ ] Check all seasonal claims, published dates, inventory and pricing
[ ] Verify test checkout and print-provider safety policies
[ ] Visual compare all screens at 360/390/768/1280/1440 widths
[ ] Preserve shipping and order lifecycle infrastructure; no unauthorized production deployment
